🌐 Linktree – Lucas Nascimento

Este é um projeto simples e elegante de Linktree personalizado, criado para centralizar meus principais links profissionais e pessoais em uma única página.
O design utiliza efeito glassmorphism, animações suaves e um layout responsivo.

✨ Funcionalidades
Layout moderno com glass effect
Totalmente responsivo para celular e desktop
Ícones do FontAwesome
Hover animado nos botões
Estrutura simples e fácil de editar

🛠️ Tecnologias Utilizadas
HTML5
CSS3 (com uso de variáveis e blur)
FontAwesome (ícones)
